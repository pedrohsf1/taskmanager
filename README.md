# TaskManager

TaskManager e um sistema de gerenciamento de tarefas que permite criar,
organizar e acompanhar as atividades da equipe.

## Funcionalidades

- Conclusao de tarefas
- Definicao de prioridade das tarefas

## Descricao da aplicacao

Permite marcar uma tarefa como concluida, alterando seu status para
"Concluida" e registrando a data de finalizacao.

Permite classificar cada tarefa com um nivel de prioridade (Alta, Media ou
Baixa) e ordenar a lista de tarefas por esse criterio.
